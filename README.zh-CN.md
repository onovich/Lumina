# Lumina

[English](README.md)

第一人称低多边形艺术探索游戏：点亮神龛，让黑白世界逐步恢复颜色。

![Lumina 封面](docs/cover.png)

## 项目包含什么

- 第一人称探索。
- 低多边形地形。
- Boids 萤火虫。

## 快速开始

安装依赖并启动本地版本：

```bash
npm install
npm run dev
```

仓库还提供 `npm run build`、`npm run test`。

## 仓库结构

- `src/` — 应用与库的源代码。
- `origin/` — 原始原型与设计资料。
- `.github` — 自动化与 GitHub Pages 工作流。
- `index.html` — Web 入口。
- `package.json` — 包脚本与依赖。

## 当前状态

仓库已经包含与上述用途对应的实现和项目材料。当前仓库没有自动化测试，评估时请在目标环境中直接运行。

# Lumina: Aether Dawn

A WebGL-based first-person 3D art exploration game. Players explore a monochromatic low-poly landscape and ignite shrines to awaken the world, bringing color back through dynamic progression.<br/>**一款基于 WebGL 的第一人称 3D 艺术探索游戏。玩家在黑白单色的低多边形风景中探索，通过点亮神龛来唤醒世界，随着进度动态带回色彩。**

## Features

- First-person exploration with dual-zone touch controls for mobile compatibility.<br/>**适配移动端的双区触控系统，实现流畅的第一人称探索。**
- Low-poly terrain generation using overlapping sine waves and smooth color interpolation.<br/>**使用多重正弦波叠加生成的低多边形地形以及平滑的色彩插值。**
- Boids algorithm implementation for guiding fireflies with dynamic target fluctuation.<br/>**基于 Boids 模拟群体特性的萤火虫引导系统。**
- Refactored into a scalable MVC architecture logic with Engine layers for future Unity C# class porting.<br/>**重构成具备高扩展性的 MVC 和独立逻辑引擎层的架构，为将来的 Unity C# 脚本移植做准备。**

## Getting Started

- Clone this repository.<br/>**克隆本仓库。**
- Install dependencies via standard node package manager (`npm install`).<br/>**使用标准 Node 包管理器安装依赖 (`npm install`)。**
- Start the Vite development server.<br/>**启动 Vite 运行开发服务。**
